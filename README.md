# @horospococl

Contenido para Instagram @horospococl.

- `reels/`: Reels de diciembre 2026 (mp4 1080x1920)
- `memes/`: carruseles de memes (jpg 1080x1350)
- `scripts/content.py`: guiones y captions
- `scripts/render.py`: genera los videos e imágenes

Make publica cada pieza en su fecha (19:00, hora de Chile) desde el data store "Calendario Reels Horospococl".
